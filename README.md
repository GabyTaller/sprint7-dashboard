# Dashboard de anuncios de venta de coches

## Descripción del proyecto

Este proyecto consiste en una aplicación web interactiva desarrollada con Python y Streamlit para visualizar información de anuncios de venta de coches.

La aplicación utiliza el conjunto de datos `vehicles_us.csv` y permite explorar visualmente la información mediante gráficos interactivos creados con Plotly.

## Funcionalidades

La aplicación incluye:

- Un encabezado descriptivo.
- Un botón para construir un histograma de la distribución del kilometraje.
- Un botón para construir un gráfico de dispersión que muestra la relación entre el precio y el kilometraje.
- Visualizaciones interactivas mediante Plotly.

## Tecnologías utilizadas

- Python
- Pandas
- Plotly
- Streamlit
