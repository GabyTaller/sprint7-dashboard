# Dashboard de anuncios de venta de coches

Esta aplicación web permite explorar un conjunto de datos de anuncios de venta de coches mediante visualizaciones interactivas.

La aplicación incluye:

- Un histograma para analizar la distribución del kilometraje.
- Un gráfico de dispersión para analizar la relación entre precio y kilometraje.
